overview: >-
  Data Oriented Architecture (DOA) is a software architecture pattern that
  creates data-driven, loosely coupled, decentralised, and open systems. DOA
  achieves these goals by exposing systems' data as a first-class citizen to
  distributed, stateless, and asynchronous components. These design decisions
  enable DOA-based systems to achieve data availability, reusability, and
  monitoring, as well as adaptability, scalability, and autonomy.
  [DOAgent](https://github.com/cabrerac/doagent) is a Python library for
  building multi-agent systems where shared data is the primary interface
  between decentralised agents that cooperate in open environments. It follows
  three principles: data as a first-class citizen, decentralisation, and
  openness. These Part II, Part III, and MPhil projects use that library.
